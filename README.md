# 迅搜 ⚡ 全盘极速文件搜索（Rust 重制版）

对标"闪电搜索 FinderPro"的功能复刻，核心链路用 Rust 重写：**NTFS MFT 直读索引 + USN 日志实时增量 + rayon 并行搜索**。

## 功能

- **全盘索引**：管理员模式下直读 NTFS `$MFT`（数百万文件秒级完成）；非 NTFS 卷或目录遍历仅在用户显式开启"遍历模式"后执行
- **即时搜索**：输入即搜，多关键字空格分隔（AND），`C:\game` 这类含 `\` 的词按路径模式匹配；追加输入时只在上次结果集上收窄
- **分类过滤**：全部 / 图片 / 文档 / 视频 / 音频 / 手机 / 目录（左侧栏带实时计数）
- **排序**：文件名 / 文件路径 / 文件大小 / 修改时间，点击表头切换升降序
- **实时更新**：USN 日志监听，新建 / 重命名 / 删除直接用日志自带字段落库（不回读 MFT），仅大小变化才按 FRN 聚簇回读
- **标记文件**：8 色标记（右键菜单或检视面板色板），持久化到配置
- **预览**：图片缩略图 / 文本内容 / 文件元信息，右侧检视面板
- **设置**：开机自启、全局热键（默认 `Alt + ~`）、排除目录、主题与行高
- **快照热启动**：索引定期持久化，重启后从快照恢复 + USN 增量回放，秒级就绪

## 界面

三栏检索工作台（设计说明 `docs/ui-redesign.md`，可交互原型 `docs/ui-mockup.html`）：

- **顶栏 64**：品牌 + 搜索框（内嵌清除与热键提示）+ 结果元信息 + 行高/预览/设置开关
- **侧栏 208**（可折 56）：分类（图标 + 文字 + 计数）、标记、索引范围、主题与设置
- **中央**：表头固定 + 虚拟化结果表，行内悬浮「打开 / 定位 / 复制 / 标记」
- **右栏 320**：预览、大小/修改时间/路径、8 色标记
- **底栏 26**：状态点 + 索引进度 + 条目总数 + 版本

深/浅双主题（默认跟随系统），行高紧凑/标准/宽松三档。宽度按 1180 / 980 / 820 / 680 四档降级：
窄屏依次把侧栏折成图标栏、收起预览、把路径下沉为行内第二行。

快捷键：`Ctrl+F` 聚焦搜索、`↑↓` 选择、`Enter` 打开、`Ctrl+Enter` 定位、`Ctrl+C` 复制路径、
`Ctrl+A` 全选、`Space` 勾选、`Alt+1..7` 切分类、`Ctrl+,` 设置、`Ctrl+R` 重建索引、`Esc` 逐级退出。

## 构建 / 运行

```bash
cargo build --release        # 需要 x86_64-pc-windows-msvc 工具链
./target/release/xunsou.exe
```

- 以**管理员身份运行**可启用 NTFS 秒级索引；否则状态栏出现「启用极速索引」徽章
- 配置、索引快照与缓存都在 `%LOCALAPPDATA%\xunsou\`，不往被索引的磁盘写任何东西

## 索引与检索设计（详见 `docs/search-algorithm.md`）

| 层 | 做法 | 代价 |
|---|---|---|
| 冷启动（一次性） | 顺序读 `$MFT`，零分配解析，紧凑条目表 | 约 1GB 顺序读 / 100 万文件 |
| 常态（持续） | USN 事件流：创建/重命名/删除零回读；大小变更按 FRN 升序聚簇回读 | O(变更量) |
| 查询（每次按键） | 前缀收窄 + rayon 并行字节匹配，分类判定零分配 | 大索引走后台线程，UI 不阻塞 |

## 无头测试（无窗口、无需显卡交互）

基于 **egui-kittest**（AccessKit 无障碍树驱动，等同 Playwright 风格）：

```bash
cargo test                                   # 全部测试（单元 + 无头 UI）
UPDATE_SNAPSHOTS=1 cargo test                # UI 变更后重新生成像素快照基线
```

> 界面重构后 `tests/snapshots/main.png` 基线已重新生成；其余断言（分类点击、键入搜索、表头排序、
> 行选中、设置开关）沿用原有 label 语义。

### 预览

| 类型 | 方式 |
|---|---|
| png / jpg / gif / bmp / webp | `image` 直接解码，超过 1600px 先缩略 |
| txt / md / 代码 / json / csv 等 | 读前 128KB 作为文本展示 |
| 视频（mp4/mkv/avi/mov…） | Windows 缩略图管线取**首帧** |
| pdf / office / heic / raw | 同上，由系统已注册的缩略图处理器出图 |

视频与文档类走 `IShellItemImageFactory`，与资源管理器同一条管线，命中缩略图缓存时几乎零 IO；
没有可用处理器时给明确空态，不会回退成通用图标。

### 删除

行尾悬浮操作与右键菜单均含「删除」：`SHFileOperationW + FOF_ALLOWUNDO` 移入**回收站**，
误删可还原，不弹确认框；失败（文件被占用等）给出明确提示。删除后结果立即消失，
重建索引后与真实磁盘对齐。

### 应用图标

`assets/` 内含 7 档尺寸的 `.ico`（exe 资源，经 `make_res.py` + `cvtres` 生成 COFF
后由 build.rs 接入链接）与窗口/任务栏图标。重新换图标见 `assets/make_res.py` 头注释。

### 界面校对（截图探针）

`app::ui_probe` 用内存索引渲染 8 个界面状态（默认 / 选中 / 设置 / 900 宽 / 660 宽 / 深色 /
行悬停 / 窄窗设置）并输出 `tests/snapshots/probe_*.png`，不触碰真实磁盘，默认 `#[ignore]`：

```bash
cargo test ui_probe -- --ignored                    # 与基线比对
UPDATE_SNAPSHOTS=1 cargo test ui_probe -- --ignored # 改界面后重新生成
```

## 代码结构

| 模块 | 职责 |
|---|---|
| `win.rs` | Win32 FFI：卷枚举 / MFT 读取 / USN / 全局热键 / 提权重启 |
| `model.rs` | 索引数据模型：紧凑条目、去重名称池、父链路径、快照序列化 |
| `indexer.rs` | MFT 解析与扫描、USN 实时增量、目录遍历回退、协调线程 |
| `search.rs` | rayon 并行匹配、增量收窄、分类计数、排序 |
| `categories.rs` | 扩展名分类（零分配） |
| `ui/tokens.rs` | 设计令牌：深/浅色板、字号阶梯、间距与圆角 |
| `ui/icons.rs` | 16×16 线性图标，Painter 自绘（不依赖 emoji 字体） |
| `ui/widgets.rs` | 图标按钮、chip、键帽、分区标题等通用控件 |
| `app.rs` | 界面装配与交互（顶栏/侧栏/结果表/检视面板/状态栏/设置） |
| `config.rs` | 配置 / 标记持久化 / 界面偏好 / 开机自启 |
